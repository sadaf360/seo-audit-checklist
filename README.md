## ✅ Crawling & Indexing

- [ ] `robots.txt` exists and does **not** block important pages
- [ ] XML sitemap exists, is submitted in Google Search Console, and only contains indexable URLs
- [ ] Search Console → Pages report: no large groups of errors or excluded pages
- [ ] Only one version of the site loads (https + preferred www / non-www)
- [ ] No important pages accidentally marked `noindex`
- [ ] Canonical tags are correct and consistent

## 📝 On-Page SEO

- [ ] Every important page has a **unique title** (≈60 characters) and meta description
- [ ] One clear **H1** per page containing the primary keyword
- [ ] Heading structure is logical (H1 → H2 → H3)
- [ ] Images have descriptive file names + proper alt text
- [ ] Internal links use clear, keyword-rich anchor text
- [ ] No duplicate or thin pages competing for the same keyword
- [ ] URL structure is clean and readable

## ⚙️ Technical SEO

- [ ] Site is fully mobile-friendly
- [ ] Core Web Vitals checked in PageSpeed Insights / CrUX
- [ ] Broken links (404s) fixed or properly redirected
- [ ] Redirect chains and loops removed
- [ ] Schema markup added and validated (Rich Results Test)
- [ ] HTTPS is forced everywhere
- [ ] Page speed is acceptable on mobile & desktop

## 📚 Content Quality

- [ ] Each target keyword has **one clear target page**
- [ ] Content fully matches search intent
- [ ] Thin or outdated content is updated, merged, or removed
- [ ] Content is helpful, original, and satisfies the user

## 📍 Local SEO (if applicable)

- [ ] Google Business Profile is claimed and fully optimized
- [ ] Name, Address, Phone (NAP) is consistent everywhere
- [ ] Categories, services, and photos are complete
- [ ] Local schema is implemented

---

## 💡 Pro Tips

- Always start with **crawling & indexing** issues — they block everything else
- Use Screaming Frog or Sitebulb for technical crawls
- Document everything with screenshots for client reports
- Re-audit every 3–6 months
