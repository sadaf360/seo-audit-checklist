# SEO Audit Checklist

Copy this list into your notes and tick items off as you audit a site.

## Crawling and indexing
- [ ] robots.txt exists and does not block important pages
- [ ] XML sitemap exists, is submitted in Search Console, and lists only indexable URLs
- [ ] Search Console Pages report: no large groups of errors or excluded pages
- [ ] Only one version of the site loads (http/https, www/non-www)
- [ ] No important pages marked noindex by mistake

## On-page
- [ ] Every page has a unique title (about 60 characters) and meta description
- [ ] One H1 per page, with the main keyword
- [ ] Headings follow a logical order (H2, H3)
- [ ] Images have descriptive file names and alt text
- [ ] Internal links point to key pages with clear anchor text
- [ ] No duplicate or thin pages competing for the same keyword

## Technical
- [ ] Site is mobile friendly
- [ ] Core Web Vitals checked in PageSpeed Insights
- [ ] Broken links (404) fixed or redirected
- [ ] Redirect chains removed
- [ ] Canonical tags set correctly
- [ ] Schema markup added and validated

## Content
- [ ] Each target keyword has one matching page
- [ ] Content answers the search intent
- [ ] Old content updated or merged

## Local (if it applies)
- [ ] Google Business Profile claimed and complete
- [ ] Name, address and phone match everywhere
